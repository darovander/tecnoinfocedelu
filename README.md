# TecnoInformática — Sitio web oficial

**Dominio:** https://tecnoinformatica-cdu.com.ar

Sitio estático listo para publicar.

## Archivos

| Archivo | Uso |
|---------|-----|
| `index.html` | Contenido y estructura |
| `styles.css` | Diseño y colores |
| `script.js` | Menú móvil, formularios → WhatsApp, lightbox |
| `logo.png` | Logo oficial (header y footer) |
| `logo-icon.png` | Ícono cuadrado (favicon) |

## Cómo publicar

1. Subí **toda la carpeta** a tu hosting (Netlify, Vercel, cPanel, Hostinger, etc.).
2. Apuntá el dominio `tecnoinformatica-cdu.com.ar` a la carpeta raíz del sitio.
3. Listo.

### Opción fácil y gratis (recomendada)
- Entrá a [netlify.com](https://netlify.com)
- Arrastrá la carpeta `tecnoinformatica-web`
- Después conectá tu dominio en Domain settings

## Cómo editar después

- **Textos** → `index.html`
- **Colores** → variables `:root` en `styles.css`
- **Fotos de trabajos** → creá carpeta `img/` y reemplazá los placeholders en la sección Trabajos
- **Logo** → reemplazá `logo.png` o `logo-icon.png` manteniendo el mismo nombre
